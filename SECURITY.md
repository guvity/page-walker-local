# Security Policy

PageWalkerLocal is intended for authorized browser QA, load checking, page walking, and statistics testing in environments where you have permission to test.

Do not use this project for:

- CAPTCHA solving or CAPTCHA bypass.
- Anti-bot bypass, stealth, or fingerprint spoofing.
- Creating fake accounts.
- Bypassing payments, deposits, subscriptions, or paywalls.
- Clicking payment, purchase, deposit, or order confirmation controls.
- External AI API driven automation.
- Local HTTP servers, MCP servers, Ollama servers, llama-server, or browser automation servers.

Report security issues privately through GitHub Security Advisories when available, or by opening a minimal issue that does not include exploit details.
